## 구현된 기능 요약

| 기능 | 내용 |
|------|------|
| 동적 지오펜스 | 내 실시간 위치를 중심으로 반경 220m 원이 따라다님 |
| 위치 공유 (opt-in) | 체크박스를 켠 사람만 3초마다 위치를 서버에 보고 |
| 설정 저장 | localStorage + DB(`users.location_share_enabled`) 양쪽에 저장, 온라인 복귀 시 동기화 |
| 상대방 마커 | 주황 점 + 이름표, 위치 갱신 시 이동, 접속 종료 시 제거 |
| 진입 이벤트 | 상대가 220m 안으로 → `⚠️ ○○님이 접근!` 상태 메시지 + 팝업 |
| 이탈 이벤트 | 안에 있던 상대가 250m 밖으로 → `🚨 범위를 벗어났습니다` |
| 히스테리시스 | 진입 220m / 이탈 250m — GPS 오차로 인한 경계 떨림 방지 |
| 연결 끊김 구분 | 범위 안에 있던 상대가 15초간 무보고 → `📡 연결 끊김` (이탈과 구분) |

## 1. 백엔드 — LocationController.java

경로: `my-app-backend/src/main/java/com/example/demo/controller/LocationController.java`

```java
package com.example.demo.controller;

import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api")
public class LocationController {

    // userId → 마지막으로 보고된 위치. DB가 아니라 서버 메모리에 보관한다.
    private final Map<Long, LiveLocation> locations = new ConcurrentHashMap<>();

    // 15초 동안 보고가 없으면 접속 종료로 간주
    private static final long STALE_MS = 15_000;

    public record LiveLocation(Long userId, String name, double lat, double lng, long updatedAt) {}
    public record LocationReport(Long userId, String name, Double lat, Double lng) {}

    // ── 내 위치 보고 ──
    @PostMapping("/locations")
    public ResponseEntity<?> report(@RequestBody LocationReport req) {
        if (req.userId() == null || req.lat() == null || req.lng() == null) {
            return ResponseEntity.badRequest().body(Map.of("message", "userId, lat, lng는 필수입니다"));
        }
        String name = (req.name() == null || req.name().isBlank()) ? "익명" : req.name();
        locations.put(req.userId(),
                new LiveLocation(req.userId(), name, req.lat(), req.lng(), System.currentTimeMillis()));
        return ResponseEntity.ok(Map.of("message", "ok"));
    }

    // ── 나를 뺀 접속자 목록 ──
    @GetMapping("/locations")
    public ResponseEntity<List<LiveLocation>> others(@RequestParam Long userId) {
        long now = System.currentTimeMillis();
        locations.values().removeIf(l -> now - l.updatedAt() > STALE_MS);   // 낡은 항목 청소
        List<LiveLocation> result = locations.values().stream()
                .filter(l -> !l.userId().equals(userId))
                .toList();
        return ResponseEntity.ok(result);
    }
}
```

**읽을 때 짚을 점 3가지**

1. `record` 2개가 컨트롤러 안에 중첩 선언돼 있다 — 이 컨트롤러 밖에서 안 쓰이니 파일을 나눌 필요가 없다.
2. `LocationReport` 의 `lat`/`lng` 는 `double` 이 아니라 **`Double`(래퍼)** 이다. `double` 이면 JSON에 값이
   없을 때 자동으로 `0.0` 이 되어 "아프리카 앞바다 좌표"가 되어버린다. `Double` 이라야 `null` 검사가 가능하다.
3. 청소(`removeIf`)를 **조회할 때 같이** 한다. 별도 스케줄러를 만들지 않아도 되는 가장 간단한 방법.

## 2. 백엔드 — AuthController 의 위치공유 설정 API

```java
@PutMapping("/users/{id}/location-sharing")     // 전체 경로: PUT /api/auth/users/{id}/location-sharing
public ResponseEntity<?> updateLocationSharing(
        @PathVariable Long id,
        @RequestBody Map<String, Boolean> body) {
    User user = userRepository.findById(id)
            .orElseThrow(() -> new IllegalArgumentException("사용자 없음"));
    user.setLocationShareEnabled(body.get("enabled"));
    userRepository.save(user);
    return ResponseEntity.ok(Map.of("id", user.getId(),
                                    "locationShareEnabled", user.isLocationShareEnabled()));
}
```

로그인 응답에도 이 값이 포함되어, 다른 기기에서 로그인해도 설정이 따라온다.

```java
return ResponseEntity.ok(Map.of(
    "id", user.getId(), "name", user.getName(), "email", user.getEmail(),
    "locationShareEnabled", user.isLocationShareEnabled()));
```

> ⚠️ 지금은 **아무나 남의 id로 이 API를 호출할 수 있다.** 인증이 붙으면 "요청자 == {id}" 검사를 넣어야 한다.

## 5. 프론트 — MapPage.js

### 5-1. 상수 + 게스트 ID 헬퍼 (컴포넌트 밖, import 아래)

```js
const GEOFENCE_RADIUS_M = 220;   // 진입 문턱
const GEOFENCE_EXIT_M   = 250;   // 이탈 문턱 (히스테리시스)

// 로그인했으면 DB의 userId, 아니면 탭 단위 임시 ID를 만들어 쓴다
function getLiveId(user) {
  if (user?.id) return user.id;
  let id = sessionStorage.getItem('liveLocId');
  if (!id) {
    id = String(1_000_000_000 + Math.floor(Math.random() * 1_000_000_000));
    sessionStorage.setItem('liveLocId', id);
  }
  return Number(id);
}
```

`sessionStorage` 는 **탭마다 별개**다. 그래서 브라우저 탭 두 개를 띄우면 서로 다른 게스트가 되어
**혼자서도 위치공유 테스트가 가능하다.** (localStorage 였다면 두 탭이 같은 ID를 공유해서 테스트 불가)

10억 이상의 큰 수를 쓰는 이유는 실제 DB userId(1, 2, 3…)와 겹치지 않게 하려는 것.

### 5-3. GPS 추적 + 내 마커 + 원 (useEffect, 의존성 `[]`)

```js
useEffect(() => {
  const map = mapRef.current;
  if (!map || !navigator.geolocation) return;

  let cancelled = false;
  geoWatchIdRef.current = navigator.geolocation.watchPosition(
    (pos) => {
      if (cancelled || !mapRef.current) return;      // 언마운트/지도 재생성 방어
      const { latitude, longitude } = pos.coords;
      lastPosRef.current = { lat: latitude, lng: longitude };

      if (!currentLocMarkerRef.current) {            // 최초 1회: 마커 + 원 생성
        currentLocMarkerRef.current = L.marker([latitude, longitude], {
          icon: makeCurrentLocationIcon(), zIndexOffset: 1000, interactive: false,
        }).addTo(map);

        geofenceCircleRef.current = L.circle([latitude, longitude], {
          radius: GEOFENCE_RADIUS_M,
          color: '#2563eb', weight: 2, opacity: 0.6,
          fillColor: '#2563eb', fillOpacity: 0.08, interactive: false,
        });                                          // ← addTo 안 함! 토글 effect가 붙였다 뗀다
        map.setView([latitude, longitude], 15);
      } else {                                       // 이후: 좌표만 이동
        currentLocMarkerRef.current.setLatLng([latitude, longitude]);
        geofenceCircleRef.current?.setLatLng([latitude, longitude]);
      }
    },
    (err) => console.warn('위치 추적 실패:', err.message),
    { enableHighAccuracy: true, maximumAge: 5000, timeout: 10000 }
  );

  return () => {                                     // 정리 — 안 하면 배터리를 계속 먹는다
    cancelled = true;
    if (geoWatchIdRef.current != null) {
      navigator.geolocation.clearWatch(geoWatchIdRef.current);
      geoWatchIdRef.current = null;
    }
    currentLocMarkerRef.current?.remove(); currentLocMarkerRef.current = null;
    geofenceCircleRef.current?.remove();  geofenceCircleRef.current = null;
  };
}, []);
```

### 5-4. 폴링 + 지오펜스 판정 (useEffect, 의존성 `[user?.id, locationShareEnabled]`)

```js
useEffect(() => {
  const map = mapRef.current;
  if (!map) return;

  let cancelled = false;
  const myId = getLiveId(user);
  const myName = user?.name || `게스트${String(myId).slice(-4)}`;
  const markers   = otherMarkersRef.current;
  const insideMap = othersInsideRef.current;

  const timer = setInterval(async () => {
    const myPos = lastPosRef.current;
    if (!myPos || !locationShareEnabled) return;     // 위치 없거나 공유 OFF면 아무것도 안 함

    try {
      await reportLocation({ userId: myId, name: myName, lat: myPos.lat, lng: myPos.lng });
      const others = (await getOtherLocations(myId)) || [];
      if (cancelled || !mapRef.current) return;      // await 사이에 언마운트됐을 수 있다

      const seen = new Set();
      for (const o of others) {
        seen.add(o.userId);

        // ① 마커: 없으면 만들고 있으면 이동
        let marker = markers.get(o.userId);
        if (!marker) {
          marker = L.marker([o.lat, o.lng], { icon: makeOtherUserIcon(), zIndexOffset: 900 })
            .bindTooltip(o.name, { permanent: true, direction: 'top', offset: [0, -10] })
            .addTo(map);
          markers.set(o.userId, marker);
        } else {
          marker.setLatLng([o.lat, o.lng]);
        }

        // ② 지오펜스 판정 (히스테리시스)
        const dist = map.distance([myPos.lat, myPos.lng], [o.lat, o.lng]);
        const wasInside = insideMap.get(o.userId) || false;
        const isInside = wasInside ? dist <= GEOFENCE_EXIT_M : dist <= GEOFENCE_RADIUS_M;

        if (isInside && !wasInside) {
          setStatus(`⚠️ ${o.name}님이 ${GEOFENCE_RADIUS_M}m 안에 접근! (거리 ${Math.round(dist)}m)`);
          marker.bindPopup(`${o.name} — ${Math.round(dist)}m 거리`).openPopup();
        } else if (!isInside && wasInside) {
          setStatus(`🚨 ${o.name}님이 범위를 벗어났습니다 (거리 ${Math.round(dist)}m)`);
          marker.bindPopup(`${o.name} — 범위 이탈 (${Math.round(dist)}m)`).openPopup();
        }
        insideMap.set(o.userId, isInside);
      }

      // ③ 이번 응답에 없는 = 접속 끊긴 유저 정리
      for (const [id, marker] of markers) {
        if (!seen.has(id)) {
          const name = marker.getTooltip()?.getContent() || '상대방';
          if (insideMap.get(id)) setStatus(`📡 ${name}님 연결 끊김`);
          marker.remove(); markers.delete(id); insideMap.delete(id);
        }
      }
    } catch {
      // 네트워크 오류는 무시 — 3초 뒤 다음 폴링에서 자연히 재시도된다
    }
  }, 3000);

  return () => {
    cancelled = true;
    clearInterval(timer);
    markers.forEach(m => m.remove()); markers.clear(); insideMap.clear();
  };
  // user 객체는 매 렌더마다 새로 생성되므로 안정적인 user?.id 에만 의존 (의도된 것)
  // eslint-disable-next-line react-hooks/exhaustive-deps
}, [user?.id, locationShareEnabled]);
```

### 5-6. 토글 핸들러 + 오프라인 대응

```js
const handleLocationShareChange = useCallback(async (checked) => {
  setLocationShareEnabled(checked);
  localStorage.setItem('locationShareEnabled', JSON.stringify(checked));   // ① 항상 로컬 저장

  if (user?.id) {
    try {
      await updateLocationSharing(user.id, checked);                       // ② 로그인 시 DB 저장
    } catch (error) {
      console.warn('오프라인: localStorage에만 저장됨', error);            // ③ 실패해도 UI는 유지
    }
  }
}, [user?.id]);

// 온라인 복귀 시 localStorage 값을 DB에 다시 밀어넣는다
useEffect(() => {
  const handleOnline = async () => {
    if (!user?.id) return;
    const localValue = JSON.parse(localStorage.getItem('locationShareEnabled') || 'false');
    try { await updateLocationSharing(user.id, localValue); }
    catch (error) { console.warn('동기화 실패', error); }
  };
  window.addEventListener('online', handleOnline);
  return () => window.removeEventListener('online', handleOnline);
}, [user]);
```

이 패턴을 **낙관적 업데이트(optimistic update)** 라고 한다: 서버 응답을 기다리지 않고 UI를 먼저 바꾸고,
실패하면 나중에 맞춘다. 체크박스처럼 되돌리기 쉬운 조작에 잘 맞는다.

## 설계 결정 메모 (왜 이렇게 했나)

| 결정 | 이유 |
|------|------|
| WebSocket 대신 3초 폴링 | 기존 REST 패턴만으로 구현 가능. 인원이 적을 때는 충분 |
| DB 대신 메모리(ConcurrentHashMap) | 3초 뒤면 낡는 데이터. 영구 저장 가치 없음 |
| 판정을 프론트에서 | "내 기준 반경"이라 각자 계산하면 됨. 서버 부하 0 |
| state 대신 ref로 좌표 보관 | GPS 갱신마다 리렌더되면 지도가 버벅임 |
| 진입 220 / 이탈 250 | GPS 오차로 인한 경계 떨림(채터링) 방지 |
| 15초 유통기한 | 브라우저를 그냥 닫으면 "종료" 신호가 안 오므로 무보고 시간으로 판단 |
| sessionStorage 게스트 ID | 탭 2개로 혼자 테스트 가능하게 |

## 테스트 방법

1. 백엔드(`gradlew bootRun`) + 프론트(`npm start`) 실행
2. 브라우저 탭 **2개**로 `http://localhost:3000/map` 열기 (한쪽은 로그아웃 상태여도 됨)
3. 두 탭 모두 왼쪽 패널의 **"위치 공유" 체크박스를 켠다**
4. 위치 권한 허용 → 각 탭에 파란 점(내 위치) + 파란 원(220m)이 보이면 정상
5. 같은 PC라 두 탭의 GPS가 동일 → 거리 0m → 서로 **즉시 진입 이벤트**가 떠야 정상
6. 상태 메시지에 `⚠️ 게스트XXXX님이 220m 안에 접근!` 이 뜨면 성공
7. 한쪽 탭을 닫고 15초 기다리면 다른 탭에 `📡 연결 끊김` 이 뜬다

> 다른 거리를 시험하려면 브라우저 개발자도구의 **Sensors → Location** 에서 좌표를 직접 바꿔보면 된다.

## 개선 후보

- 위치 공유 범위를 **같은 파티(링크) 멤버로 한정** — 지금은 접속자 전원에게 보인다
- WebSocket(STOMP)으로 전환 → 지연 3초 → 즉시
