## 1. 캔바로 넘기는 방법 (둘 중 하나)

| | 방법 | 장점 | 주의 |
|---|---|---|---|
| **A (추천)** | 캔바 홈 → **업로드** → `PedalLink_팜플렛.pptx` → 열면 편집 가능한 디자인으로 변환 | 지금 레이아웃 그대로 시작 — 캔바에선 다듬기만 | 폰트가 맑은 고딕 → 캔바 폰트로 바뀜(아래 3번 폰트로 일괄 변경), 그림자·둥근 이미지 일부가 달라질 수 있음 |
| **B** | 캔바 AI에 **4번 프롬프트** + `canva_assets/` 이미지 업로드 → 생성 후 **5번 명세**대로 수정 | 캔바 템플릿 감성으로 새로 디자인 | AI 결과는 매번 다르고 문구가 바뀔 수 있음 → 5번 원고로 꼭 덮어쓰기 |

공통 설정: **맞춤형 크기 210 × 297 mm (A4 세로)**, 인쇄할 거면 파일 → **재단 물림 표시** 켜고 상단 파란 배경·하단 남색 푸터는 재단선 밖까지 늘리기. 내보내기는 **PDF 인쇄** (재단 물림 + 재단선 표시 체크).

## 4. 캔바 AI 프롬프트 (복사해서 붙여넣기)

```
A4 세로(210×297mm) 한 장짜리 프로젝트 전시용 홍보 전단을 만들어 줘.
서비스: PedalLink — 서울 자전거 경로 안내 및 협동 라이딩 웹 플랫폼.
톤: 깔끔하고 밝은 테크 스타트업. 메인색 하늘색 #0284C7, 보조 #0EA5E9, 글자·푸터 남색 #0C1B27, 강조 노랑 #FFCC4D(제목 한 줄만). 폰트는 한글 고딕(Pretendard 또는 Noto Sans KR). 장식 줄 없이 여백 넉넉하게.

구성(위→아래):
1) 상단 35%: 진한 하늘색 그라데이션 배경. 왼쪽 위 로고+"PedalLink", 작은 알약 라벨 "서울 자전거 경로 안내 · 협동 라이딩 플랫폼", 큰 제목 3줄 "근처 라이더와 / 지금 바로, / 함께 달리는 자전거"(마지막 줄 노랑), 그 아래 "코스를 만들고, 근처 라이더와 함께 달리고, 기록을 나누는 서울 자전거 플랫폼입니다.", 흰 알약 3개 "01 코스 만들기 · 02 함께 달리기 · 03 기록·공유". 오른쪽에 휴대폰 목업(업로드한 라이딩 화면).
2) 제목 "라이딩 준비, 이런 점이 불편했죠" + 연한 카드 3칸(아이콘 원, 취소선 문제 → 굵은 해결): 자동차 중심 길안내 → 자전거도로를 먼저 고르는 경로 / 팀 라이딩 중 이탈·낙오 → 실시간 위치 공유와 근접 알림 / 함께 달릴 사람 구하기 → 220m 근처 라이더 매칭·크루.
3) 제목 "PedalLink로 이렇게 달려요" + 흰 카드 3개(위: 업로드한 앱 화면, 아래: 번호+제목+글머리표 3줄): 01 코스 만들기 / 02 함께 달리기 / 03 기록·공유.
4) 연한 하늘색 띠에 큰 숫자 4개: 2,673 서울 자전거도로 구간 / 100곳 경유지 최대 / 220m 근처 라이더 매칭 반경 / 25개 구 코스 지역 자동 분류.
5) "기술 스택" + 알약 배지: React 19 · Vite, Leaflet, BRouter, Spring Boot 4 · Java 21, JPA · Hibernate Spatial, PostgreSQL 18 + PostGIS, WebSocket (STOMP), Rocky Linux · Nginx, Cloudflare Tunnel.
6) 맨 아래 남색 푸터: "TEAM PEDALLINK" 팀원 3명(김호성 조장 · 신재원 · 임연수)과 역할, 개발기간 2026. 07 ~ 2026. 11, GitHub github.com/hosung5287-creator/Pedal_link.
```

> 캔바 AI 입력창 글자 수가 모자라면 1)~3)만 먼저 넣어 생성하고, 4)~6)은 5번 명세를 보고 직접 추가.
