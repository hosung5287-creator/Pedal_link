# PedalLink 프로젝트 전체 기술 스택 개요

## 아키텍처 구조

```
브라우저 (React 19)
    │
    ├── Leaflet ─── OpenStreetMap 타일 서버 (지도 배경)
    ├── fetch ───── BRouter API        (자전거 경로 계산)
    └── fetch ───── Kakao Local API    (장소 검색)
    │
    ↕ HTTP (JSON) — api/client.js 를 통해서만 호출
    │
Spring Boot 4.0.6 서버 (Java 21, 포트 8080)
    │
    ├── AuthController      회원가입·로그인·위치공유 설정
    ├── RouteController     경로 저장/조회/삭제
    ├── CyclewayController  자전거도로 GeoJSON
    ├── PartyController     파티(링크) 모집·신청·승인
    ├── RideRecordController 주행 기록 저장·조회
    ├── FeedController      둘러보기 피드·좋아요
    └── LocationController  실시간 위치 보관·중계 (메모리, DB 아님)
    │
    ↕ JDBC (Spring Data JPA / Hibernate)
    │
PostgreSQL 18 + PostGIS
    users / routes / cycleways / parties / party_members / ride_records / route_likes
```

## 라우팅 구조 (프론트)

React Router를 쓰지 않고 `window.history` 로 직접 구현했다. 진입점은 `src/App.js`.

| 경로 | 컴포넌트 | 설명 |
|------|----------|------|
| `/` | HomePage | 랜딩 + 최근 코스 캐러셀 |
| `/map` | MapPage | 지도·경로탐색·저장·위치공유·라이딩 (핵심 화면, ~1000줄) |
| `/login` | LoginPage | 이메일 로그인 |
| `/signup` | SignupPage | 회원가입 |
| `/party` | PartyPage | 파티(링크) 모집·신청 |
| `/browse` | BrowsePage | 둘러보기 피드 (다크 테마) |

로그인 유저는 `localStorage.user` 에 `{ id, name, email, locationShareEnabled }` 형태로 보관된다.
(서버 세션/토큰 없음 — 자세한 한계는 [07_Spring_Security.md](07_Spring_Security.md) 참고)
