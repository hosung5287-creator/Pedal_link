## 1. 설정 — 이메일·비밀번호 변경, 위치 공유

- **이메일 변경** `PUT /api/users/{id}/email` `{ currentPassword, newEmail }` — 현재 비밀번호로 본인 확인. 형식 400 · 비밀번호 틀림 401 · 중복 409. 성공하면 프로필 응답.
- **비밀번호 변경** `PUT /api/users/{id}/password` `{ currentPassword, newPassword }` — 8자 이상, 현재와 같으면 400.
- 소셜 계정(비밀번호 없음)은 둘 다 400 — 프론트는 서버 문구를 그대로 보여준다(B안).
- 이메일을 바꾸면 `App.handleUserUpdate` 가 로그인 정보(localStorage `user`)도 바로 고친다 → 다시 로그인 안 해도 프로필 상단에 반영.
- **위치 공유 스위치**(useLocationShare): 서버 값(`users.location_share_enabled`)이 기준. 브라우저 사본은 **사용자별 키** `locationShareEnabled:{id}`. 저장 실패 시 pending 표시 후 온라인 복귀 때 재전송.
- 오류 문구 꺼내기 공용 함수 `api/client.js` `errorMessage(err, fallback)` — 서버의 `{ message }` 만 꺼낸다.

## 2. 상승고도 — 탄 거리만큼 인정, km당 상승

- 상승고도는 **GPS 측정값이 아니다.** 코스를 만들 때 BRouter 가 지형 고도로 계산한 `filtered ascend` 를 `routes.ascend_m` 에 저장해 둔 예상값.
- 라이딩 기록은 `route_id` 만 저장하고, 통계에서 조인한다. 이때 **코스 상승고도 × min(1, 탄 거리 ÷ 코스 거리)** 만 인정 → 122m 코스를 30m 만 타면 거의 0.
- `/api/ride-records/stats` 에 `ascendPerKm` (총 상승 ÷ 코스 라이딩 거리) 추가. 자유주행은 분모에서 뺀다("0m" 가 아니라 "모름").
- 지도 화면 라이딩도 불러온/저장한 코스면 `routeId` 를 보낸다(전에는 항상 자유주행이었음).
- 버그 수정: 상승고도가 null 인 옛 코스를 탄 사용자는 `Collectors.toMap` NPE 로 통계·목록이 500 이었다.
- GPS 고도를 쓰지 않는 이유: 수직 오차 10~30m 누적, PC 브라우저는 값 없음, 웹은 기압계 불가, 화면 꺼지면 수집 중단.

## 3. 게시물 지역 = 코스 출발점이 들어 있는 구

- 우선순위: 경로 만들기의 **지역 선택**(구를 골라 뒀으면) → 아니면 **출발점이 들어 있는 구**.
- 처음엔 카카오 API 였지만 키가 없어 늘 실패 → 자전거도로(`cycleways.gu`) 최근접 방식은 **구 표기가 틀려서**(잠실→강남구) 버림 → **서울 구 경계 폴리곤**(`seoul_gu`, 통계청 2013 · southkorea/seoul-maps Apache-2.0)으로 `ST_Covers` 판정.
- 마이그레이션 **005** 에 경계 데이터가 SQL 로 들어 있다(약 880KB, GDAL 불필요). 원본 강서구 경계가 자기교차라 `ST_MakeValid` 로 고쳐 넣는다. 기존 코스 지역도 같은 규칙으로 채움.
- `RegionService.findGu(lat, lng)` — 서울 밖이면 null. `seoul_gu` 가 없는 DB 면 경고만 남기고 null(저장은 막지 않음).
- 글쓰기 창은 지역을 **보여주기만** 하고 보내지 않는다. 백엔드 `publish` 는 region 이 null 이면 코스 값을 유지.
- 프론트 `GU_LIST` 에 **서대문구** 추가(자전거도로 데이터엔 없지만 경계 기준으로는 나온다).

## 4. 피드 작성자 프로필 창 · 공개 프로필 API

- `GET /api/users/{id}/public` → `PublicProfileResponse`: 이름·소개·자전거·성별·나이·지역·가입일. **이메일·위치 공유 설정·로그인 방식은 싣지 않는다.**
- ⚠ 기존 `GET /api/users/{id}` 는 여전히 누구에게나 이메일을 준다 — 서버에 로그인 인증이 없어서 막을 수 없음(별도 과제).
- `components/UserProfileModal.jsx` — 기본 정보 + 라이딩 통계. 피드·지도·도크·개인 라이딩이 같이 쓴다. `badges` 옵션, z-index 2150(라이딩 화면 위).
- "로그인한 사람만"은 화면에서 막는다. 비로그인 좋아요 클릭 시 오류 나던 버그도 수정(이벤트 전달).

## 5. 위치 공유 off 를 모든 화면에 일관 적용

- 전에는 **개인·파티 라이딩 화면이 스위치와 상관없이** 3초마다 내 위치를 보냈다 → 이제 꺼져 있으면 보내지 않는다(다른 사람 위치는 계속 본다). 화면에 "위치 공유 꺼짐 [켜기]" 안내.
- 실시간 위치는 서버 메모리에 15초 보관 → 끄는 즉시 `DELETE /api/locations?userId=` 로 지운다.
- 실시간 위치 보관소를 `LiveLocationService` 로 분리(위치 API·파티·크루 라이딩이 공유). 하버사인 거리 계산 포함.
- 위치 공유가 켜져 있으면 **파티 도크가 어느 화면에서든** 5초마다 위치를 보고한다(근처 판정에 필요).

## 6. 근처(호스트 220m) 모집 중 링크만 보이고 신청 가능

- `GET /api/parties?userId=` — 내 파티(호스트·참여·신청 중)는 항상, 남의 파티는 **모집 중 + 나와 호스트 둘 다 위치 공유 중 + 220m 안**일 때만. 응답에 `hostDistanceM`.
- `POST /api/parties/{id}/apply` 도 서버에서 다시 거리 확인 — 사유: 위치 공유를 켜야 / 호스트가 공유 중 아님 / "호스트와 220m 안에 있어야 (지금 약 500m)".
- 범위 상수 `PartyService.PARTY_RANGE_M = 220` (프론트 `NEAR_M` 과 같은 값).
- 파티 페이지의 "위치 공유 켜기" 버튼은 요청으로 삭제 — 켜기는 도크·설정에서.
- 기존 링크 3개(1·2·4번, test1)와 그 채팅 15건은 삭제함(라이딩 기록 1건은 보존).

## 7. 경로 만들기 경유지 (최대 100곳)

- 흐름: 출발 → 경유지(추가한 순서대로) → 도착. **출발지를 먼저 정해야** 경유지 추가 가능.
- 추가: 지도 우클릭 "경유지로 추가"(어두운 노랑 `#ca8a04`) 또는 패널 "+ 경유지 추가"(장소 검색). 삭제: 패널 × 또는 **마커 팝업 [삭제]**.
- BRouter `lonlats=출발|경유1|…|도착` 으로 자전거·최단 경로 모두 계산.
- 저장: `routes.waypoints` (JSON 텍스트 `[{lat,lng,label}]`, 마이그레이션 **006**). 불러오기·파티 코스에서 경유지까지 복원해야 재계산해도 같은 경로가 나온다. 저장 목록에 "경유 N곳".
- 백엔드는 Jackson 3(`tools.jackson.databind.json.JsonMapper`)으로 직렬화. 101곳 이상은 400.

## 9. 크루 "이번주 라이딩 열기"

```
팀장: 열기 (제목·날짜·가입 멤버 선택·코스)          crew_events(recruiting) + crew_event_members(invited)
  → 크루 채팅 초대 카드 (type RIDE_INVITE)
멤버: [참여]/[불참] → "정말 참여할까요?" 2차 확인       accepted + 토큰(당일 23:59:59 만료) / declined
팀장(당일): 인원 체크 시작                              checking, 무응답 → declined
팀장: 사람별 [체크] / [근처 인원 모두 체크]             팀장 220m 안 + 유효 토큰 → checked (안 되면 사유)
팀장: 라이딩 시작                                       팀장+체크 인원으로 파티 생성(full·라이딩 시작) → riding
체크된 멤버: 어느 화면이든 라이딩 화면 자동 이동       /api/me/status 의 crewRiding
```

- 크루당 진행 중인 라이딩 1개. 체크 못 한 사람은 합류 불가. 시작 전에는 팀장이 취소 가능.
- 체크 거리 `CrewRideService.CHECK_RANGE_M = 220` (임시값 — 상수 하나만 바꾸면 된다).
- 토큰 값은 응답에 싣지 않는다(서버에서만 확인). 화면엔 만료 시각만.
- 라이딩 화면·위치·기록은 **파티 기능 재사용**(`PartyService.createCrewRideParty`).
- 마이그레이션 **007**: `crew_events` 에 `route_id·status·party_id`, 새 테이블 `crew_event_members`.

| 항목 | 전 | 후 |
